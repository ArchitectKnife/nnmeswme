# BURGER SKIN — версия 4: каталог, 47 новых кейсов, изображения и кинодропы

## Установка на рабочую базу

Ничего не удаляется: пользователи, балансы, инвентари, ставки, леджер и журнал аудита не изменяются (скрипт проверяет это сам).

```bash
npm run backup          # на всякий случай (seed:cases4 тоже делает копию перед записью)
npm start               # миграция базы №4 применяется автоматически при запуске
npm run seed:cases4     # каталог v4 + 47 новых кейсов (повторный запуск безопасен)
npm run audit:images -- --online   # проверка всех изображений сайта
npm run images:sync     # по желанию: сохранить на сервер оставшиеся изображения CDN Steam
```

Пробный запуск без записи: `npm run seed:cases4 -- --dry-run`. Отчёт о каждом запуске — `data/catalog/seed-v4-report-*.json`.

Опции `seed:cases4`:
- `--refresh-prices` — обновить и существующие цены значениями из пакета (по умолчанию добавляются только отсутствующие);
- `--update-cases` — пересобрать состав кейсов v4 по пакету (только кейсы с источником `seed-v4`; кейсы, созданные вручную, не трогаются);
- `--keep-local-images` — не заменять локальные изображения `/img/items/*` неизвестного происхождения.

### Источники

- **Предметы и изображения**: [ByMykel CSGO-API](https://github.com/ByMykel/CSGO-API) (MIT) — `skins.json` и `skins_not_grouped.json`, данные из файлов игры. Изображения — официальный CDN Steam (`community.akamai.steamstatic.com`).
- **Цены**: выгрузка публичного API Skinport в рублях (`data/prices-rub.json`, 37 243 записи, обновлены 09.11.2026 13:50 UTC). Прямой запрос к API Skinport из среды разработки блокируется Cloudflare (HTTP 403), поэтому использован этот файл; запустите `npm run import:prices` на сервере, чтобы обновить цены.
- Предмет попадает в кейс, только если у него есть настоящая цена для **всех** возможных качеств (и для StatTrak, если он возможен). 13 запланированных скинов исключены по этому правилу (дешёвые отделки ножей без цены StatTrak FN) — см. `catalog/v4/build-report.json`.

### Изображения

- 1 725 изображений для всех 678 предметов новых кейсов (все качества) хранятся локально в `public/img/skins/<предмет>/<качество>.webp` (WebP с прозрачностью, исходное разрешение 512×384, всего 27 МБ).
- Остальные изображения каталога — проверенные адреса CDN Steam через кеширующий прокси сайта; `npm run images:sync` сохраняет их на сервер.
- Игрок видит изображение именно своего качества: в инвентаре, рулетке, результате открытия, кинодропе, Case Battle, апгрейдере и профиле.
- Обложки кейсов — композиция из 1–3 настоящих предметов кейса на абстрактном фоне темы (13 тем: вспышка, лучи, соты, сетка, кольца, карбон, волны, схема, призма, рельеф, полосы, точки, осколки) и цвете кейса. Ни одного сгенерированного или постороннего изображения. Сочетание «тема + цвет + предметы» уникально для каждого кейса; одинаковые авто-обложки старых кейсов разведены.

## Каталог кейсов

Вкладки категорий с иконками и счётчиками (Все, Рекомендуемые, Новые, Стартовые, Премиум, Ножи, Перчатки, Легендарные, Тематические, По оружию), поиск по названию и по скину, быстрые диапазоны цены и свой диапазон, сортировка (популярность по реальному числу открытий, новизна, цена, отдача, название), дополнительные фильтры по оружию. Без фильтров — витрина рекомендуемых кейсов и разделы по категориям; на телефоне — одна колонка витрины и прокручиваемые вкладки.

На странице кейса: точные шансы каждого предмета и качества (4 знака), сумма шансов, ожидаемая стоимость и отдача, изображения всех качеств предмета, бейдж фазы.

## Админ-панель

- **Кейсы** (`/admin/cases/:id`): «Рекомендуемый», тема обложки, цвет кейса, категории, кнопка «Точно 100%» (целые веса с суммой 1 000 000, пропорции сохраняются), сумма весов в реальном времени.
- **Обложки** (`/admin/covers`): тема фона и цвет для каждого кейса, выбор 1–3 предметов или своё изображение.
- **Скины** (`/admin/items/:id`): изображения по качеству с проверкой файла и источника; API `POST /api/admin/items/:id/wear-image` для замены изображения качества.
- **Проверка изображений** (`/admin/images`).
- **Кинодропы** (`/admin/drops`): пороги уровней, уровень запуска сцены, минимальный уровень для ножей и перчаток.

Все изменения пишутся в журнал аудита; права проверяются на сервере (`cases.manage`, `items.manage`, `settings.manage`).

## Честность

- Предмет выбирает сервер (Provably Fair, HMAC-SHA256) и записывает в инвентарь до ответа клиенту. Кинодроп только показывает уже выданный предмет; его уровень вычисляется по цене выданного предмета и сохраняется в ставке.
- Пороги кинодропов не меняют шансы — это проверяют `npm run test:cine` и `npm run test:v4`.
- Каждый предмет каждого кейса реально может выпасть (непустой диапазон билетов), частоты 200 000 серверных бросков совпадают с заявленными шансами (тест).
