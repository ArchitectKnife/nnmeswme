# BURGER SKIN — Cinematic Drop v5 (STANDARD / RARE / EPIC / LEGENDARY / GODLIKE + KNIFE / GLOVE)

Полностью новая система кинематографичного показа редкого дропа. Файлы уже в проекте — отдельный установщик больше не нужен
(прежний `install-cinematic.mjs` удалён: он устанавливал старую сцену версии 3 и перезаписал бы новую).

## Настройка

Админ-панель → Система → **Кинодропы** (`/admin/drops`):
- пороги уровней в рублях: RARE / EPIC / LEGENDARY / GODLIKE (по умолчанию 1 500 / 5 000 / 25 000 / 100 000 ₽; при обновлении старые пороги GODLIKE / MYTHIC / DIVINE перенесены в EPIC / LEGENDARY / GODLIKE);
- **уровень запуска сцены** (по умолчанию RARE; STANDARD — сцена для каждого дропа);
- минимальный уровень для ножей и перчаток (по умолчанию EPIC), отдельные сцены KNIFE и GLOVE;
- условие «не дешевле N × цены кейса», режим по умолчанию (полные / короткие / выкл), облегчённый режим по умолчанию, ссылки «Поделиться»;
- статистика: сколько цен каталога в каждом уровне, вероятность каждого уровня и сцены по каждому кейсу;
- предпросмотр всех 7 сцен.

У игрока: режим «Полные / Короткие / Выкл» на странице кейса, в самой сцене — звук, облегчённые эффекты, пропуск, повтор, «Поделиться».

## Сцена

Стадии: нарастание (тьма, гул, пробуждение энергетического ядра, дым и частицы) → активация (портал / разлом, объёмные лучи, волны энергии, искажение света) → напряжение (движение камеры, импульсы света, паузы; предмет не показывается) → (только GODLIKE: «раскол реальности») → раскрытие (вспышка, ударная волна, искры и осколки) → финальная презентация (предмет на отражающей платформе, контровой свет, металлический блик, глубина резкости, орбита камеры, карточка с названием, качеством, float, фазой, StatTrak/Souvenir и ценой).

| Уровень | Образ и звук |
|---|---|
| STANDARD | цвет редкости предмета, световая сфера, одна волна, чистое раскрытие, лёгкий аккорд |
| RARE | синий разрез → портал, лучи, две волны, искры, лёгкая тряска камеры |
| EPIC | фиолетовый разлом с нитями энергии, «вертиго»-наезд, осколки, вспышка и ударная волна, арпеджио |
| LEGENDARY | багрово-золотой разлом с молниями, сильный наезд камеры, тяжёлый удар, световые колонны |
| GODLIKE | почти полная тишина и сердцебиение, раскол «стекла» реальности, золотая сверхновая в замедлении, призматические цвета, уникальный хор и колокола |
| KNIFE | холодная сталь, световые лезвия-росчерки, вращение предмета, звук «клинка» |
| GLOVE | изумрудно-бирюзовая гамма, поднимающиеся ленты света, мягкое покачивание, кожаный «щелчок» |

Предмет — настоящее изображение Steam именно выпавшего качества (WebGL-плоскость с освещением по контуру, бликом, толщиной и отражением). Цвета предмета не искажаются; если изображение недоступно, показывается нейтральная рамка «Изображение предмета недоступно», а не чужая картинка.

Звук синтезируется WebAudio (без сторонних файлов и без чужой музыки), идёт через общий канал «Кинодропы» и учитывает настройки звука игрока и админа.

## Производительность и доступность

- WebGL2 → Canvas2D (и при потере контекста) → только DOM-карточка; сторож переходит к результату, если отрисовка зависла.
- Три уровня качества с автоматическим понижением по FPS; на телефоне — средний уровень и меньше частиц.
- Облегчённый режим (`bs_cine_lite`): включается вручную, по умолчанию из админки, автоматически при ≤ 4 потоках CPU или ≤ 2 ГБ памяти.
- `prefers-reduced-motion`: без тряски, вспышек и быстрого движения — мягкое появление.
- Пауза во вкладке в фоне, освобождение ресурсов при закрытии, Escape / «Пропустить» / клик вне предмета.
- Модуль и стили грузятся лениво только при кинодропе.

## Честность

- Предмет выбирается сервером (Provably Fair) и записывается в инвентарь до ответа клиенту; сцена только показывает этот предмет.
- Уровень сцены сервер считает по цене уже выданного предмета и сохраняет в ставке; пороги влияют только на выбор сцены — шансы кейсов не меняются (`npm run test:cine`, `npm run test:v4`).
- Сцена не делает запросов, кроме сохранения личных настроек звука; промис `playDrop` всегда завершается.
